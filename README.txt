REPAIR GURU TOOLS — WEBSITE + INSTALLABLE PWA STARTER

Included:
- index.html: responsive website prototype
- manifest.webmanifest: app metadata
- sw.js: basic offline caching
- icons/: app icons

How to test:
1. Unzip this package.
2. Upload all files/folders to an HTTPS static host (for example, GitHub Pages or Netlify).
3. Open the published HTTPS website in Android Chrome.
4. Use the Install App button if shown, or Chrome menu > Add to Home screen / Install app.

Important:
- A PWA can be installed on Android from the browser; it is not yet a signed APK from the Play Store.
- For a Play Store app, you will need an Android wrapper/build process, app signing, store listing, privacy policy and testing.
- Login/signup are demo-only. Payments, real AI, verified sensor/error-code database and AdSense are not connected yet.
- Ads must be added after hosting and after approval by the ad network.
